# 모바일웹서비스프로젝트 실습 4 - Python Socket Server

클라이언트가 보낸 HTTP 요청을 직접 확인하기 위한 Python 소켓 서버입니다.
요청 원본을 이진 파일로 저장하고, multipart/form-data로 전송된 이미지를 별도 파일로 추출합니다.

## 실습 내용

**실습 1. 요청 원본 저장**
클라이언트의 요청을 가공 없이 `request/` 폴더에 `년-월-일-시-분-초.bin` 이름의 이진 파일로 저장합니다.

**실습 2. 멀티파트 이미지 저장**
multipart/form-data로 전송된 이미지 데이터를 추출해 별도 이미지 파일로 저장하고, 저장된 파일이 정상적으로 열리는지 확인합니다.

## 프로젝트 구조

```
.
├── server.py        # 소켓 서버 소스 코드
├── response.bin     # 클라이언트에게 보내는 HTTP 응답
└── request/         # 저장된 요청(.bin) 및 이미지 파일
```

## 실행 방법

```bash
python server.py
```

서버는 `127.0.0.1:8000`에서 실행되며, `Ctrl+C`로 종료합니다.

### 실습 1 테스트

브라우저에서 `http://127.0.0.1:8000`에 접속하면 요청이 `request/` 폴더에 `.bin` 파일로 저장됩니다.

### 실습 2 테스트

```bash
curl -F "file=@test.png" -H "Expect:" http://127.0.0.1:8000/
```

요청 원본(`.bin`)과 추출된 이미지(`.png`)가 같은 타임스탬프 이름으로 `request/` 폴더에 저장됩니다.

## 구현 방식

**요청 수신**
헤더의 끝(`\r\n\r\n`)까지 먼저 수신한 뒤, `Content-Length` 값만큼 바디를 추가로 수신합니다. 이렇게 하면 타임아웃을 기다리지 않고 요청 전체를 받을 수 있습니다.

**멀티파트 파싱**
`Content-Type` 헤더에서 boundary 값을 추출해 바디를 파트 단위로 나눕니다. `filename`이 포함된 파트에서 파트 헤더 이후의 바이너리 데이터만 잘라내고, 원본 파일명의 확장자로 저장합니다. 파트 끝의 CRLF는 `rstrip` 대신 마지막 2바이트만 제거해 이미지 데이터가 손상되지 않도록 했습니다.

## 결과 파일

| 파일 | 설명 |
|---|---|
| `request/YYYY-MM-DD-HH-MM-SS.bin` | 클라이언트 요청 원본 |
| `request/YYYY-MM-DD-HH-MM-SS.png` | multipart 요청에서 추출한 이미지 |
